# Ectropy v0.6.1

This release inherits Plumb v0.18.21 so `ectropy skill` discovers Grok the
same way it discovers Claude and Codex, and installs the owned brief at
`~/.grok/skills/ectropy`.

Ownership, ledger, force, upgrade, and uninstall are unchanged. An unmanaged
path is still refused even when a matching marker is present.

The governed document surface in this release is `AGENTS.md`, `DESIGN.md`, and
the ectropy brief. The former free-floating docs were folded there on main
after v0.6.0.

The sixteen laws and `ectropy law` are unchanged.
