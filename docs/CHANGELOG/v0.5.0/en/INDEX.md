# Ectropy v0.5.0

## KISS refuses anonymous models

KISS is now Ectropy's top-level principle: simple code makes its models
explicit. Each concrete law names one mechanically visible projection; `kiss`
itself is never a finding or suppression label.

The new `combination` law refuses a Boolean expression that combines a fourth
decision atom. Connected `&&` and `||` expressions count across parentheses and
negation, while combinations inside calls remain independent. Rust closure
prefixes, TypeScript regex lexical goals, and TSX prose boundaries are handled
by their adapters.

The default `[limit] combination` value is three. A finding points to the
`combination` cookbook, which distinguishes temporal state from orthogonal
classification and rejects merely hiding the same expression behind a helper.

## Smaller, clearer diagnostics

The `receiver` law now reports one finding for each crowded receiver group and
names every member in source order. Its finding also links to the receiver
cookbook.

Plain `.css` files now join `.scss` files in the scanned source set and carry
the same whole-file style marker.

## Compatibility retirement

The hidden inert `--strict` spelling promised only for the v0.4 line has been
removed. `--strict` and `--debt` are both invalid; every finding already blocks
the single normal scan mode.
