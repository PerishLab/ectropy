# combination

## Trigger

The `combination` error reports a Boolean expression carrying more than three decision atoms.

## Move

Name the combination model, not only the predicate. Facts that vary through time become an explicit state and transition. Orthogonal facts become a classification, pattern, decision table, or domain type. A helper that retains the same oversized Boolean expression has only moved the finding.

## Evidence

Four independent Boolean facts admit up to sixteen combinations. The expression names one selection while leaving valid states, impossible states, and ownership of the combination implicit.

## EXIT

Remove this entry when the combination classification and remedy become mechanical or the combination law retires.
