# Restrained scenarios

## A finding names terrain the law does not govern

Add a boundary only for mechanically identifiable territory, keep its path
narrow, and write the real reason. A boundary changes where a law applies; it is
not a tolerated diagnostic, and nothing checks that its rationale is true. A
`ban` finding has no boundary route: `allow` accepts the other fifteen names
only, so move the syntax or change the ban.

## A name looks like it should be registered

Register a term only for a compound the product already speaks. A term added to
clear one finding freezes a dictionary nobody agreed to.

## Coverage refuses a region

The parser did not understand that syntax. Decide whether the file belongs in
the scan set or the language needs an adapter; an adapter is a grammar resource
and a namespace atom spec, never a new crate.
